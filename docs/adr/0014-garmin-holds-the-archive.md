# Garmin holds the archive

Garmin already stores the athlete's training. Cardio City does not keep a second copy of that archive. The session cache holds the mapped sessions in the six-week window, which size the city, and the ten most recent sessions in each district, so the top of the list opens immediately. Opening an older session fetches it from Garmin. Gravel, yoga, and the other sports the city does not show are not cached. A later district can read them from Garmin at that time.
