# Swim is drawn as two sub-districts

Pool swimming and open-water swimming are different places in the Swim district, and each has its own size. An athlete who only uses the pool gets a huge pool and a remnant lake. One swim object scaled by every swim would hide that split, so the skyline does not work that way.

Swim still groups them. The size module scores Pool and Open water separately. Artwork inside one sub-district scales together. Opening the pool or the lake opens the Swim record filtered to that sub-district. Statistics, records, the last competition, and the full session list stay on Swim.
