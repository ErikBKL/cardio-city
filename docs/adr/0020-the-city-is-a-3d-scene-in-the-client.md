# The city is a 3D scene drawn in the client

The athlete rotates the city, sees it from above and on a diagonal, zooms, and moves along its streets. Hovering an object shows an aura. Clicking it plays a bump and opens that district's record. Three.js draws the scene inside the web app. All of that is client rendering. The backend still supplies sizes, sessions, and stats. It does not draw frames, and it does not run a game simulation.
