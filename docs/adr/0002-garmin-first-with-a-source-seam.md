# Garmin is the first source, behind a source seam

Athletes will connect Strava and Apple as well as Garmin. V1 reads sessions from Garmin only. Ingestion goes through a source boundary, so a later source can deliver sessions without reshaping the city, the districts, or session history. The same real-world session still counts once when a second source appears.

A second source does not, by itself, supply a load figure the city can use. Which figures count as load is a separate decision.
